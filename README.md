# 暖心待辦看板（kanban-app）

用拖放（drag and drop）管理待辦事項的單頁看板，純 HTML、CSS、JavaScript 撰寫，不需安裝或建置，資料存在瀏覽器本機。

## 線上展示

https://n731110nk.github.io/kanban-app/

## 功能

- **新增任務**：輸入任務內容，可選填負責人，並選擇分類（工作／生活）與優先程度（High／Medium／Low，預設 Medium），點 **新增任務** 後卡片會出現在 **To-do** 欄位。
- **三欄狀態看板**：**To-do**（待辦）、**Process**（進行中）、**Done**（已完成），每欄標題旁顯示卡片數量。
- **拖放移動**：把卡片拖到其他欄位即可變更狀態。
- **自動排序**：各欄位內依 High → Medium → Low 排列；相同優先程度的卡片，可以拖曳調整前後順序。
- **分類篩選**：上方 **全部**、**工作**、**生活** 分頁切換顯示範圍，分頁旁顯示該分類的任務總數。
- **刪除**：點卡片右上角的 × 刪除單一任務；**Done** 欄位有卡片時會出現 **清除 Done** 按鈕，一次刪除所有已完成任務。
- **今日資訊**：頁首顯示今天日期，以及尚未完成（To-do 與 Process）的任務數。
- **窄螢幕版面**：畫面寬度 960px 以下時，三個欄位改為上下排列。

## 本機使用方式

不需安裝任何套件，也不需建置。

1. 下載或複製（clone）本專案：

   ```bash
   git clone https://github.com/n731110NK/kanban-app.git
   ```

2. 用瀏覽器直接開啟專案資料夾裡的 `index.html`。

## 檔案結構

```
kanban-app/
├── index.html                    頁面結構：頁首、新增表單、篩選分頁、三個狀態欄位
├── style.css                     版面與視覺樣式，含窄螢幕版面
├── app.js                        所有互動邏輯：新增、刪除、拖放、排序、篩選、存取本機資料
├── .gitignore                    排除 macOS 系統檔與 Office 暫存檔
└── .agents/rules/docs-writing.md 撰寫本專案文件時遵守的規則
```

## 部署方式

本專案以 GitHub Pages 發布，來源為 `main` 分支根目錄。推送到 `main` 後，網站通常會在幾分鐘內自動更新：

```bash
# 在專案資料夾執行
git add .
git commit -m "說明這次改了什麼"
git push
```

GitHub Pages 的設定位置在 repo 的 **Settings → Pages**，介面可能因 GitHub 改版而不同，請參考[官方文件](https://docs.github.com/pages)。

## 已知限制

- **資料只存在目前的瀏覽器**：任務存在瀏覽器的 `localStorage`（鍵值 `minimalist_todos_v1`）。換瀏覽器、換裝置、使用無痕視窗或清除瀏覽器資料，都看不到原本的任務；也沒有帳號或多人共用功能，每位訪客只會看到自己的任務。
- **只能用滑鼠拖放變更狀態**：沒有按鈕或鍵盤操作可以移動卡片，鍵盤使用者無法變更任務狀態。
- **觸控裝置可能無法拖放**：拖放使用瀏覽器原生的 HTML 拖放功能，部分手機與平板瀏覽器不支援，在這些裝置上卡片可能拖不動。
- **不能編輯既有任務**：任務建立後無法修改內容、負責人、分類或優先程度，需要刪除後重新新增。
- **跨優先程度的位置不會保留**：把卡片拖到不同優先程度的卡片之間，放下後仍會依優先程度重新排列。
